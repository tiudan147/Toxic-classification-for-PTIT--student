# Comment Scraper v1.22.0 — Scraper-Only Hardening

> **Quy trình:** Requirements → Design → Tasks → Code (mỗi task có verify + commit riêng).

**Goal:** Biến extension thành scraper-only triệt để (không telemetry, không remote fetch, không driver đăng bài trên trang FB), tăng độ bền vòng cào, và thêm quan sát/kiểm thử được.

**Architecture:** content.js dựng lại từ đầu chỉ còn: ping handler + config local + scraper driver (dùng pure helpers từ `lib/scraper-core.js` — file dùng chung cho content script, UI và unit test Node). Background giữ nguyên cơ chế pause/stop, chỉ thêm progress theo URL.

**Tech Stack:** Chrome MV3, vanilla JS, `node:test` cho unit test (không cần DOM).

---

## 1. Requirements

- **R1 — Scraper-only triệt để (content script):**
  - R1.1 Không gửi bất kỳ dữ liệu nào ra server thứ ba (hiện đang có Sentry + Mixpanel inline trong content.js — vi phạm nguyên tắc dữ liệu ở máy local).
  - R1.2 Không fetch config remote (`fbgroupbulkposter.com` / Firebase) — dùng file `domselector.config.json` đóng gói sẵn trong extension.
  - R1.3 Không inject driver đăng bài (~2.200 dòng) vào mọi trang Facebook nữa.
- **R2 — Độ bền vòng cào:**
  - R2.1 Early-stop: 3 lượt scroll liên tiếp không có bài mới thì dừng, không đốt hết maxScrolls.
  - R2.2 Time budget mỗi URL (mặc định 4 phút) — luôn nhỏ hơn timeout 5 phút của background, không bao giờ bị background cắt ngang.
  - R2.3 Ghi nhận `expectedComments` (số comment FB hiển thị) so với số cào được — phát hiện selector hỏng ngay trong kết quả.
- **R3 — Quan sát được (observability):**
  - R3.1 Log buffer (≤200 dòng) lưu `chrome.storage`, hiển thị 15 dòng cuối trong UI.
  - R3.2 Progress: URL thứ i/N, số bài, số comment theo thời gian thực.
- **R4 — Kiểm thử:**
  - R4.1 Logic thuần (parse author từ aria-label, dedupe key, xuất CSV) tách ra `lib/scraper-core.js`, có unit test chạy `node --test` không cần trình duyệt.
- **R5 — Dọn repo:**
  - R5.1 Xoá file chỉ phục vụ đăng bài: `index.html`, bundle React (`assets/main-*`), `firebase-*.js` (khỏi manifest), `InjectBridge.js`, `store_listing_texts/`, notes cũ.
  - R5.2 Bump version 1.22.0.

**Không làm (YAGNI / nợ có chủ):** dọn background.js (~3.400 dòng code đăng bài còn sót nhưng dormant — các route đăng bài đã bị chặn ở v1.21.0; xoá sâu rủi ro cao hơn lợi ích). Ghi nhận làm việc tương lai.

## 2. Design

**Dataflow giữ nguyên:** UI → `startScrapePosts` → background (mở cửa sổ nhỏ `focused:false` mỗi URL, pause `waitBeforeNextPost` giữa các URL) → content `contentScrapePosts` → viết `scrapedPosts` + `operationDone` vào storage → background gom `scrapeResults` → UI poll hiển thị.

**File thay đổi:**

| File | Thao tác |
|---|---|
| `lib/scraper-core.js` | Tạo mới — pure helpers, UMD-guard cho node:test |
| `tests/scraper-core.test.js` | Tạo mới — `node --test` |
| `content.js` | Dựng lại: ping + defaultConfig + loadConfig local + scraper section (thêm early-stop, time budget, log buffer, expectedComments, ScraperCore) |
| `scraper.html` / `scraper.js` | Progress i/N + counters + log tail + expected/actual + CSV qua ScraperCore |
| `background.js` | Viết `scraperProgress.urlIndex/totalUrls` mỗi URL |
| `manifest.json` | Bỏ firebase khỏi content_scripts, thêm `lib/scraper-core.js`, v1.22.0 |
| Xoá | `index.html`, `assets/main-*`, `firebase-*.js`, `InjectBridge.js`, `store_listing_texts/`, `HOTFIX_NOTES.txt`, `RELEASE_NOTES.txt`, `VERSION_1.19_CHANGES.md` |

**Verify mỗi task:** `node --test tests/` (task 1), `node -e "new Function(...)"` cho mọi JS sửa, `JSON.parse(manifest)`, grep phủ định (không còn sentry/mixpanel/fbgroupbulkposter trong content.js), commit + push, verify remote bằng API.

**Rủi ro:** selector DOM FB chưa test live (cần mq chạy 1 URL thật) — giảm thiểu bằng log buffer + expected/actual để chẩn đoán nhanh. Ping handler phải giữ (`background.js` checkContentScriptReady cần `{pong:true}`).
